# Thư Mục Ứng Dụng

Sử dụng `app/` cho mã nguồn ứng dụng. Tổ chức file theo framework, công cụ build, yêu cầu môn học và quy ước nhóm đã chọn; template này không quy định package hoặc kiến trúc triển khai.

Có thể bắt đầu bằng các thư mục mã nguồn, cấu hình, tài nguyên và kiểm thử nếu phù hợp. Đây chỉ là gợi ý; hãy dùng cấu trúc mà công cụ hoặc dự án yêu cầu.

## Bắt Đầu

- Thay thế hoặc xóa hướng dẫn này khi cấu trúc dự án đã ổn định.
- Không đưa file sinh tự động, trạng thái IDE, secret hoặc cấu hình local vào Git.
- Đặt tên rõ ràng, tránh hardcode giá trị quan trọng nên nằm trong cấu hình hoặc nơi lưu trữ dữ liệu của dự án.
- Ghi lệnh build, chạy và kiểm thử riêng của dự án trong README.
- Giữ tài liệu yêu cầu và cài đặt được duy trì thống nhất với phần triển khai.
- Cập nhật script cơ sở dữ liệu khi schema đã chọn thay đổi và ghi thay đổi đáng chú ý trong `CHANGELOG.md`.
