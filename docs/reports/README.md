# Báo Cáo Dự Án

Chỉ lưu các báo cáo mà dự án dự định duy trì và chia sẻ qua Git. Không lưu dữ liệu riêng tư, thông tin xác thực, nhật ký cá nhân, kết quả sinh tự động hoặc báo cáo local của Agent trong thư mục này.

Với mỗi báo cáo được duy trì, nêu mục đích, người phụ trách hoặc đối tượng đọc khi phù hợp, cùng bằng chứng nguồn. Tuân thủ quy tắc xử lý dữ liệu của dự án.
